# Security

## Scope

Security issues include memory/bounds errors, malformed-input handling, unsafe persistent-file operations, path traversal, unsafe loading, privilege-boundary mistakes and any condition where untrusted content can cause unintended code or data modification.

## Reporting

Do not publish sensitive exploit details in a public issue. Use GitHub private vulnerability reporting/security advisories when available.

Include affected revision, platform/environment, reproduction, expected/observed behaviour and known impact.

## Response

Reproduce, add regression coverage where practical, fix the underlying contract and validate the affected platform or persistence boundary.

## Supported source

Current main and the current release line are the primary maintained sources unless explicitly documented otherwise.
