# Infiltrator Calc Roadmap

The roadmap is deliberately staged. The long-term calculator can be broad without making the first release broad.

## Foundation

- [x] Portable expression evaluator.
- [x] Native GTK4 application shell.
- [x] Keyboard-first expression entry.
- [x] Core regression test target.
- [x] Exact Infiltratr Common gitlink.
- [x] MB Corpo font preference with system fallback.

## Standard calculator

- [ ] Robust integer and floating-point numeric model.
- [ ] Percentage semantics.
- [ ] Calculation history.
- [ ] Variables and memory.
- [ ] Constants.
- [ ] Configurable display precision.

## Scientific

- [ ] Trigonometric functions.
- [ ] Logarithmic and exponential functions.
- [ ] Roots and powers.
- [ ] Factorial, combinations and permutations.
- [ ] Degree/radian/gradian modes.

## Engineering and systems

- [ ] Engineering notation.
- [ ] SI prefixes.
- [ ] Unit conversions.
- [ ] Storage calculations.
- [ ] Network/subnet calculations.
- [ ] Data-rate and transfer-time calculations.
- [ ] Programmer hexadecimal/binary/octal modes.
- [ ] Date/time and epoch calculations.

## Advanced

- [ ] Statistics.
- [ ] Graphing.
- [ ] Equation solving.
- [ ] Complex numbers.
- [ ] Arbitrary precision.
- [ ] Symbolic mathematics.

A feature is complete only when implementation, tests and documented behaviour are aligned.
